# News2Value — фронтенд

Прототип интерфейса интернет-банка Альфа-Бизнес с сервисом персонализированной новостной аналитики.

## Стек

- React 19 + TypeScript
- Vite (сборка и dev-сервер)
- React Router (страницы)
- CSS Modules, дизайн-токены в `src/styles/tokens.css`

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откроется http://localhost:5173.

По умолчанию данные берутся из моков (`src/mocks`), бэкенд не нужен. Моки компаний, профилей и инсайтов — копия `data/mocks` из веток `feat/backend` / `feat/agent`.

Кнопка «Обновить анализ» в ленте запускает агента (`POST /companies/{id}/insights/refresh`). В режиме моков вместо агента подставляются `src/mocks/agent-insights.json` и `agent-runs.json` — это настоящий вывод агента из `feat/agent`, прогнанного на тех же компаниях в режиме `LLM_MODE=stub` (без модели). Как и на бэкенде, новые карточки заменяют прежние до перезагрузки страницы.

Карточка события (`/analytics/:id`) показывает 6 блоков из поля `details` с метками «Факт / Аналитика банка / Вывод AI» у каждого утверждения. Если `details` нет (агент ещё не запускался), карточка собирается в краткой версии из основных полей инсайта.

Чтобы ходить в настоящий бэкенд:

1. Запустите бэкенд (он слушает `http://127.0.0.1:8000`).
2. Скопируйте `.env.example` в `.env` и поставьте `VITE_USE_MOCKS=false`.
3. Перезапустите `npm run dev`.

Фронт шлёт запросы на `/api/...`, а dev-сервер Vite пересылает их на бэкенд без префикса `/api`. Поэтому браузер видит один адрес, и настраивать CORS не нужно.

Ключей LLM во фронтенде нет и быть не должно.

## API

Типы в `src/types.ts` повторяют контракт бэкенда (`docs/api-contract.md` в ветке `feat/backend`). Все запросы собраны в `src/api/client.ts`, имитация бэкенда для моков — `src/api/mockApi.ts`.

## Структура

```
src/
  api/         запросы к бэкенду (client.ts), имитация бэкенда на моках (mockApi.ts)
  mocks/       демо-данные
  state/       выбранная компания-клиент (общая для всех экранов)
  utils/       форматирование и перевод полей инсайта в метки интерфейса
  components/
    layout/    шапка, боковое меню, общий каркас
    home/      виджеты главного экрана
    ui/        иконки, метки «факт / банк / AI», уровень влияния
  pages/       экраны
  styles/      токены и глобальные стили
  types.ts     типы данных (поля профиля компании — по колонкам CSV кейса)
```

## Доступность

Интерфейс делается с опорой на ГОСТ Р 52872-2019 (требования доступности, основан на WCAG 2.1, уровень AA):

- контраст текста к фону не ниже 4.5:1;
- видимый фокус и полная работа с клавиатуры, ссылка «Перейти к основному содержимому»;
- семантическая разметка (`header`, `nav`, `main`, заголовки по уровням), `lang="ru"`;
- цвет не единственный носитель смысла: у уровня влияния и меток источника есть текст;
- уважение настройки «уменьшить анимацию».
