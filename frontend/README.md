# News2Value — фронтенд

Прототип интерфейса интернет-банка Альфа-Бизнес с сервисом персонализированной новостной аналитики.

## Что умеет

| Экран | Что на нём | Критерии кейса |
|---|---|---|
| Главная (`/`) | Карточка-вход «Новостная аналитика» с тремя главными событиями и пункт меню со счётчиком | 09 |
| Лента (`/analytics`) | События выбранной компании, фильтры (поиск, период, влияние, тип, источник), сортировка, кнопка «Обновить анализ» (запуск агента) | 01, 06 |
| Карточка события (`/analytics/:id`) | 6 блоков с меткой «Факт / Аналитика банка / Вывод AI» у каждого утверждения, источники, признаки компании | 02, 03, 04, 06 |
| — чат справа | Уточняющие вопросы по событию и история ответов | 10 |
| — «Как сделан этот вывод» | Трассировка: шаги агента со временем и данными, источники, признаки профиля, версия промпта | 11, 12 |
| — «Разбор был полезен?» | Оценка и причина («не про нас», «неточно»…) | 08 |
| Вход (`/`, если на сервере `AUTH_ENABLED=true`) | Форма входа и подсказка с тестовыми пользователями | — |

## Стек

- React 19 + TypeScript
- Vite (сборка и dev-сервер)
- React Router (страницы)
- CSS Modules, дизайн-токены в `src/styles/tokens.css`. Шрифты и иконки сторонних наборов не подключаются: иконки — свои SVG, шрифт — системный.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откроется http://127.0.0.1:5173.

### Режим моков (по умолчанию)

Данные берутся из `src/mocks`, бэкенд не нужен. Компании `c-001`…`c-003`, их профили и инсайты — копия `data/mocks` бэкенда. Кнопка «Обновить анализ» подставляет `agent-insights.json` и `agent-runs.json` — настоящий вывод агента из `feat/agent`, прогнанного на тех же компаниях в режиме `LLM_MODE=stub` (без модели). Вопросы в чате получают ответ-шаблон по полям карточки. Всё живёт в памяти и сбрасывается при перезагрузке страницы, как и в режиме `USE_MOCKS=true` на бэкенде.

### С настоящим бэкендом

1. Запустите бэкенд (`docker compose up -d` в корне, API на `http://127.0.0.1:8000`).
2. Скопируйте `.env.example` в `.env` и поставьте `VITE_USE_MOCKS=false`.
3. Перезапустите `npm run dev`.

Фронт шлёт запросы на `/api/...`, а dev-сервер Vite (на сервере — nginx из `deploy/web.Dockerfile`) пересылает их на бэкенд без префикса `/api`. Браузер видит один адрес, поэтому CORS не нужен.

- **Компании.** При выключенном входе (и у администратора) в шапке — демо-компании с готовыми инсайтами: `U_67064`, `U_19717`, `U_16346` (список можно поменять в `VITE_DEMO_COMPANY_IDS`). Обычный пользователь видит только свою компанию.
- **Вход.** Фронт спрашивает `GET /auth/me`. Если на сервере `AUTH_ENABLED=true`, показывается форма входа; токен хранится в браузере и уходит в заголовке `Authorization: Bearer …`. На 401 форма входа показывается снова.
- **Выручка.** У компаний из данных банка единицы не подтверждены, поэтому подпись — «по данным банка», без «млрд ₽»; при `revenue_known=false` — «нет данных».
- **Пустая лента.** Показывается подсказка сервера (`hint`). Если обновление уже идёт (`refresh_job_id`), кнопка «Обновить анализ» сама дожидается его окончания.

Ключей LLM во фронтенде нет и быть не должно.

## API

Типы в `src/types.ts` повторяют контракт бэкенда (`docs/api-contract.md`, модули B1–B9). Все запросы собраны в `src/api/client.ts`, имитация бэкенда для моков — `src/api/mockApi.ts`.

## Структура

```
src/
  api/         запросы к бэкенду (client.ts), токен входа (token.ts), имитация бэкенда (mockApi.ts)
  mocks/       демо-данные
  state/       вход (Auth.tsx) и выбранная компания-клиент (CurrentCompany.tsx)
  utils/       форматирование, фильтры, перевод кодов признаков в подписи
  components/
    layout/    шапка, боковое меню, общий каркас
    home/      виджеты главного экрана
    feed/      карточка ленты, фильтры, кнопка запуска агента
    insight/   блоки карточки события, чат, трассировка, оценка
    ui/        иконки, метки «факт / банк / AI», уровень влияния
  pages/       экраны
  styles/      токены и глобальные стили
  types.ts     типы данных
```

## Доступность

Интерфейс делается с опорой на ГОСТ Р 52872-2019 (требования доступности, основан на WCAG 2.1, уровень AA):

- контраст текста к фону не ниже 4.5:1;
- видимый фокус и полная работа с клавиатуры, ссылка «Перейти к основному содержимому»;
- семантическая разметка (`header`, `nav`, `main`, заголовки по уровням), `lang="ru"`;
- цвет не единственный носитель смысла: у уровня влияния и меток источника есть текст;
- живые области (`aria-live`) для статуса агента, ответов чата и счётчика ленты;
- уважение настройки «уменьшить анимацию».
