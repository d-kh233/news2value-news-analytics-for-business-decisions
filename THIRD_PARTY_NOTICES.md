# THIRD_PARTY_NOTICES

Сторонние компоненты, модели, данные, сервисы и смоделированные интеграции, используемые в решении News2Value (Альфа-Хакатон 2026, кейс «Новостная аналитика для принятия бизнес-решений»).

Лицензии указаны по данным проектов на момент сборки; полные тексты — в репозиториях соответствующих проектов. Строки с пометкой **[заполнить]** уточняются владельцами частей до финального тега.

## 1. Языковые модели (генеративные LLM)

Вызываются через API организаторов хакатона по командному ключу; модели не разворачиваются и не дообучаются командой. Используются только модели из утверждённого списка кейса (Приложение 3).

| Модель (id в API) | Где используется |
|---|---|
| `google/gemma-4-26b-a4b-it` | разметка новостей: тип события, факты, отрасли, движения макрофакторов, шум |
| `z-ai/glm-5.3-flash` | персонализированная интерпретация события; самопроверка (критик) и доработка |

Остальные модели из списка (`qwen/qwen3.6-35b-a3b`, `deepseek/deepseek-v4.1-flash`, `qwen/qwen3-vl-30b-a3b-instruct`, `moonshotai/kimi-k2.6`) в решении не используются. Условия использования моделей — по правилам API организаторов.

Модели эмбеддингов не используются: поиск по тезисам банка и сопоставление новости с профилем компании — BM25 (собственная реализация, `agent/retrieval.py`).

## 2. Данные

| Данные | Происхождение | Как используется |
|---|---|---|
| `df_Uid_data_hack.csv`, `df_Fid_Uid_link_hack.csv`, `df_Uid_payment_hack.csv` | обезличенные данные кейса (организаторы, АО «Альфа-Банк») | профили компаний и связи; в публичный доступ не выкладываются, только в приватный репозиторий с доступом жюри |
| 9 аналитических материалов Центра макроэкономических исследований Альфа-Банка | материалы кейса (Приложение 2) | аналитиком команды выписаны 20 тезисов с указанием источника (`agent/data/bank_theses.json`); тексты материалов в решение не копируются |
| Синтетические новости (`agent/data/mock_news.json`, `llm/eval/test_set.json`, `llm/tests/test_news.json`) | составлены командой, помечены как MOCK / демо | разработка, тестирование и демонстрация; не являются реальными публикациями |
| Карта «ОКВЭД → чувствительность к макрофакторам» (`llm/okved/okved_sensitivity.csv`) | составлена командой (промпт-инженер, проверка аналитиком) на основе разделов ОКВЭД 2 (ОК 029-2014, общедоступный классификатор) | ранжирование и объяснение влияния события на отрасль |
| Внешние новости **[заполнить]** | источники и способ сбора — бэкенд | только сайты, правила которых разрешают автоматический сбор; хранятся заголовок, дата, ссылка на первоисточник |

## 4. Смоделированные интеграции

| Интеграция | Как смоделирована |
|---|---|
| Вход из интернет-банка Альфа-Бизнес | точка входа на главном экране — макет; пользователь считается авторизованным (по разъяснению организаторов) |
| Авторизация и роли пользователей | тестовые пользователи с ролями (собственник, гендиректор, финдиректор, казначей и др.) **[заполнить: как задаются]** |
| Каталог продуктов банка | не используется; в рекомендациях — только общие категории продуктов без условий и ставок |
| Режим воспроизведения для жюри | записанные ответы моделей (`replay_cache/`) позволяют пройти сценарий без командного ключа |
