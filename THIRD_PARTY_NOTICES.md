# THIRD_PARTY_NOTICES

Сторонние компоненты, модели, данные, внешние источники и смоделированные интеграции решения News2Value (Альфа-Хакатон 2026, кейс «Новостная аналитика для принятия бизнес-решений»).

Как заполнено: версии библиотек — из lock-файлов (`backend/uv.lock`, `frontend/package-lock.json` ветки `feat/frontend`), лицензии — из метаданных пакетов (поля License-Expression / License / классификаторы PyPI, поле `license` в package-lock). Ничего не дописано по памяти. Где данных нет, стоит **TODO** с указанием, кто заполняет. Полные тексты лицензий — в репозиториях проектов.

## 1. Языковые модели (LLM)

Вызываются через API организаторов хакатона по командному ключу. Модели не разворачиваются и не дообучаются командой. По правилам кейса допустимы только модели из утверждённого списка (Приложение 3).

|---|---|---|
| `google/gemma-4-26b-a4b-it` | разметка новостей: тип события, факты, отрасли, движения макрофакторов, шум | указано ML-командой; **TODO (ML-команда): подтвердить по финальному прогону** |
| `z-ai/glm-5.3-flash` | персонализированная интерпретация события; самопроверка (критик) и доработка | указано ML-командой; **TODO (ML-команда): подтвердить** |
| `deepseek/deepseek-v4.1-flash` | задан в `.env.example` как `LLM_MODEL_RESEARCH`, в коде агента вызовов не найдено | **TODO (ML-команда): используется ли; если нет — убрать переменную** |

**TODO (ML-команда):** сверить таблицу со списком разрешённых моделей кейса и указать условия использования (по правилам API организаторов). Модели эмбеддингов не используются: поиск по тезисам банка и сопоставление новости с профилем — BM25 (собственная реализация, `agent/retrieval.py`).

## 5. Смоделированные интеграции (моки и заглушки)

| Интеграция | Как смоделирована |
|---|---|
| Вход из интернет-банка Альфа-Бизнес | не реализован: в интерфейсе точка входа — макет. В API — свой вход по email и паролю (`POST /auth/login`, JWT) |
| Пользователи и роли | тестовые пользователи `scripts/create_demo_users.py`: admin, собственник и финдиректор стройкомпании U_67064, казначей сети АЗС U_19717. Пароль — `DEMO_USER_PASSWORD`. Регистрации, восстановления пароля и OAuth нет |
| Данные банка о клиентах | синтетика `data/synthetic/` вместо CSV кейса, если их нет (`seed_demo.py --source synthetic`) |
| Поток новостей | синтетические новости `data/synthetic/news.json` вместо RSS, когда нет интернета; моковые новости агента (`NEWS_SOURCE=mock`) |
| Генератор инсайтов без ML | заглушка `ML_MODE=fake` (`backend/app/ml_ports/fake_port.py`): совпадение слов профиля с новостью, `generated_by=fake` |
| Модель недоступна | `LLM_MODE=stub` — карточки агента по шаблонам (`generated_by=rules`); дайджест и ответ на вопрос — склейка заголовков и шаблонный ответ (`generated_by=fallback`) |
| Лента, дайджест, вопросы без БД | запасной режим `USE_MOCKS=true` — моки `data/mocks/` (компании `c-001…c-003`) |
| Каталог продуктов банка | не используется: в рекомендациях только общие категории продуктов без условий и ставок |
| Режим для жюри без ключа | `LLM_MODE=replay` — записанные ответы моделей (`replay_cache/`) |
